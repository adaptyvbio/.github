# Security policy

Report security vulnerabilities in any Adaptyv repository, website, app or API to **security@adaptyvbio.com**. Do not open a public issue or pull request for them.

Encrypt sensitive details with our OpenPGP key:

- Key: <https://adaptyvbio.com/.well-known/pgp-key.txt>
- Fingerprint: `1F45 12C4 3DD6 85ED 6725  30A2 6917 07AD DC59 087D`

Include the affected repository, URL or component, the steps to reproduce, and the impact.

Our [vulnerability disclosure policy](https://adaptyvbio.com/security) gives the scope, the rules, the safe harbor and our response times. Our contact details are also in [security.txt](https://adaptyvbio.com/.well-known/security.txt).
